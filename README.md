# MODU 空間組合器

以 Three.js 製作的極簡模組建築設計工具。標準空間盒尺寸為 **2.4 × 3.6 × 2.8 m**，支援網格吸附、模組增刪、旋轉、複製、樓層切換、材質切換、面積統計與 JSON 配置匯出。

## 線上版本

- ChatGPT Sites: https://modu-space-builder.purple-fir-6468.chatgpt.site/
- GitHub Pages: 啟用 Pages 後可由本儲存庫直接發布

## 檔案

- `index.html`：操作介面與 Three.js 匯入設定
- `styles.css`：極簡建築工作台版面
- `app.js`：3D 場景、模組規則與互動功能

## 使用方式

直接開啟 GitHub Pages 網址，或在本機以 HTTP server 開啟根目錄。

## 技術

Three.js · OrbitControls · HTML · CSS · JavaScript
